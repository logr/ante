## Why vendored

The avatar color rule in the handoff spec is `HCT(hue, chroma 16, tone N)`, and the contrast
guarantee it makes depends on HCT tone being L\*. Compose Material 3 has an HCT implementation but
it is `internal`; MDC-Android's is `@RestrictTo`; nothing publishes it as public API. The solver
is one function, so it is carried here rather than pulling a library for it.

## Modifications

- Translated from Java to Kotlin, formatted by ktfmt like the rest of the module. Names, argument
  order, comments and lookup tables are kept as upstream so the files stay diffable.
- Package renamed to `io.appkitchen.ante.core.designsystem.hct`; all types `internal`.
- Members the solver does not use are dropped. `HctSolver.solveToCam` is dropped with them, so
  `Cam16` is not ported; `ViewingConditions` inlines the one `Cam16` matrix it reads.
- Behavior is pinned by `HctSolverTest`, whose fixture values were generated by the upstream Java
  at the commit above.

Nothing else is changed. Fixes go upstream first, then get re-ported.
